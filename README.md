# Expense Tracker

A modern Expense Tracker web application built using React. This application allows users to manage their income and expenses, track their balance, and store transaction data locally in the browser.

## Features

* Add income and expense transactions
* View total balance
* Track total income and expenses
* Delete transactions
* Persistent data using Local Storage
* Responsive design
* Dark Black & Red Theme

## Technologies Used

* React
* JavaScript (ES6+)
* CSS3
* Vite

## Installation

```bash
git clone https://github.com/your-username/expense-tracker.git
cd expense-tracker
npm install
npm run dev
```
